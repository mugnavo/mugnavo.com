# mugnavo.com

This repository contains the source code for Mugnavo's website, built with Astro and Tailwind CSS.

https://mugnavo.com

## Getting started

Install dependencies and run the dev server:

```bash
pnpm install
pnpm dev
```

Format and type check:

```bash
# run all
pnpm check

# or separately
pnpm format
pnpm typecheck
```

Build for production:

```bash
pnpm build
pnpm preview
```
